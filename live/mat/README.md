# 對決的牌桌底圖

給主持人用的牌桌底圖，配合讀牌器設計：鏡頭畫面的四個角對準底圖上的四個角標，兩個牌位就落在讀牌器預設的位置，不用再拖框。

| 檔案 | 尺寸 | 用途 |
|---|---|---|
| `duel-mat-a4.pdf` | 297 × 210 mm（A4 橫式） | 一般印表機就能印 |
| `duel-mat-a3.pdf` | 420 × 297 mm（A3 橫式） | 四周多一圈留白 |
| `duel-mat-600x350.pdf` | 600 × 350 mm | 送印成桌墊（常見的滑鼠墊／遊戲墊尺寸） |
| `*.svg` | 同上 | 要改顏色或文字時用 |
| `*.png` | 預覽圖 | 只是預覽，不要拿來印 |

三種尺寸中間的圖是同一張、同樣大小，差別只在四周的留白。

重新產生：`node mat/build-mat.js`。換兩側的文字：`node mat/build-mat.js 左邊的字 右邊的字 輸出資料夾`。

## 設計上配合讀牌器的地方

- **鏡頭畫面是底圖中間 278.6 × 156.7 mm 的範圍**（16:9，A4 放得下），四個角有米色的角標。手機橫放、畫面四角對準角標；斜拍時在「桌面校正」把四個點拖到角標上。
- **牌位照讀牌器的預設版面**（`public/games.js` 的 `duel.layout`）。牌位很高（佔畫面高度的 72%），所以畫面範圍可以小。一張撲克牌（63 × 88 mm）佔牌位高度的 78%，在 1920 × 1080 的畫面裡牌高約 610px，遠高於建議的 240px。
- **牌位裡面是素色的。** 紅、藍外框畫在讀牌器搜尋範圍（牌位外擴 8%）之外，讀牌器量桌面顏色的那一圈是乾淨的。牌位中央的四個小角記是幾乎同色的深綠，只給人眼對位用。
- **兩個牌位分在畫面兩側**（中間隔約 81 mm），手在一張牌上動作時不會碰到或遮到另一張。
- **兩邊的名稱各自放在自己那一格的正上方**，白字配該邊顏色的底塊（A4 版字高約 31 mm，A3 約 68 mm，桌墊版約 96 mm）。不用靠顏色或箭頭去對，印成黑白也是淺色字配深色底。名稱在鏡頭畫面之外，不影響讀牌。
- **底圖上沒有牌堆與收牌的位置。** 牌堆和用過的牌放在四個角標圍起來的範圍之外，就不會被讀到。
- **左紅右藍**，和主持台的用語（「請發牌到：紅方」）對得上。手機如果上下顛倒架，左右會對調；上方有「讀牌器畫面的上方」的箭頭。

## 驗證

用真的讀牌器頁面看這張底圖（合成畫面）：空桌時兩個牌位都是「空」、覆蓋 0%；26 張牌放上去 26 張都讀對；每次收牌後牌位都清空（A4 版實測；三種尺寸中間的圖相同）。

還沒有實際印出來測過。印刷的注意事項：

- **材質要霧面**（布面桌墊、霧面紙或霧面上膜）。亮面會反光，讀牌會受影響。
- **照 100% 實際尺寸印**，不要「縮放以符合頁面」。印好後量一下四個角標之間應該是 279 × 157 mm。A4 版四周只留約 9 mm，印表機要能印到那麼靠邊；印不到的話角標會被切掉一點，不影響使用，只是對位時少了參考。
- 送印時問清楚出血：檔案沒有另外加出血，底色是滿版的同一個綠色，裁切多一點少一點都不影響。
- 底色是深綠（`#1f5e3a`）。印出來偏淺或偏藍都沒關係，重點是和牌的白色差得夠多、整片均勻。
